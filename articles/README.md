# ブログ記事の追加

1. `articles/` に `2026-11-05-seasonal-update.md` のような英小文字・数字・ハイフンのファイル名で記事を作成します。
2. 次のメタデータを先頭に書き、その後にMarkdown本文を記入します。

```md
---
title: "記事のタイトル"
date: "2026-11-05"
category: "お知らせ"
excerpt: "一覧に表示する短い紹介文"
---

記事本文を書きます。
```

3. 実際の作業事例は、掲載許可を得たうえで、個人や施設が特定されないようにしてください。架空の口コミ・実績は掲載しません。
4. GitHubへ変更を反映すると、Cloudflare Pagesのビルドでブログ一覧・記事ページが生成されます。

使えるメタデータは `title`、`date`、`category`、`excerpt` です。日付は `YYYY-MM-DD` 形式にしてください。
